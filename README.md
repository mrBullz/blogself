# Блог SelfAI — редизайн

Самостоятельная адаптивная страница блога, оформленная по главной https://selfai.team: Inter, белый фон, холодные серые поверхности, синий акцент, оригинальный логотип и округлые кнопки.

Откройте index.html в браузере либо раздавайте эту папку статическим сервером. Основной лендинг Serenta в родительской папке не изменён.

Реализованы закреплённые разделы, ссылки #articles / #cases / #webinars / #education, поиск по материалам, тематический фильтр, сброс, пустое состояние, дозагрузка, мобильное меню и поддержка reduced motion.

В каталоге 15 материалов: 14 с исходной страницы блога и одна новая статья «Как выбрать первый ИИ-пилот и проверить его результат». Новая статья открывается локально в article.html; её оформление находится в article.css, интерактивность — в article.js. Текст подготовлен для этого макета. Счётчики показывают фактическую локальную подборку, а не заявленные на исходном сайте 24/17/31 материалов. Карточки ведут на существующие страницы SelfAI; вебинары ведут в общий каталог, как на исходном сайте. Гайд ведёт на страницу Serenta, ссылка на PDF не предоставлена исходной страницей. Подписка сохраняет исходный mailto-сценарий.

Фотографии и логотип загружаются с selfai.team, шрифт — с Google Fonts. При интеграции рекомендуется перенести их в существующий пайплайн ресурсов основного сайта.

Для публикации на selfai.team/blog необходимо перенести страницу в репозиторий основного сайта и подключить реальный каталог материалов. Эта папка не изменяет действующий сайт.
